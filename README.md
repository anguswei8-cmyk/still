# 拾影 / Still

后续能力、优先级与验收条件见 [迭代计划](docs/ITERATION-PLAN.md)。高级功能按本机计算或用户自备 API Key 逐步实现，不引入会员、订阅或付费解锁；截图、系统 OCR 和文字整理在本机处理，OCR 结果另提供由用户明确发送的 API 文字校对。

C++ / Qt 6 实现的本机优先截图与剪贴板工具，面向 Windows 和 macOS。主窗口、场景侧栏、剪贴板列表、截图历史与偏好使用 Qt Quick/QML；截图选区、编辑器、贴图和原生辅助对话框保留 Widgets。支持截图、编辑、复制、保存、贴图、直接选择贴图中的文字，以及持久化剪贴板历史。macOS 已在 Apple Silicon / Qt 6.12 下编译通过；Windows Qt 6.8.3 / MinGW 已完成构建、26 组回归及部分原生专项，范围与待办见 [Windows 验证记录](docs/WINDOWS-VALIDATION.md)。

## 运行

Windows 构建后运行 `build/Still.exe`，部署后运行 `dist/Still/Still.exe`。启动显示剪贴板单列列表；内容侧栏切换剪贴板／已固定／截图历史，底部偏好进入四类设置，返回内容位于分类上方，截图入口位于内容区右下角。macOS 主窗口打开时显示 Dock 图标，最小化后保留；关闭或收起后切回辅助应用模式常驻菜单栏，可通过菜单栏或全局快捷键重新打开，在菜单栏选择“退出”才结束进程。分发时保留整个部署目录及 Qt DLL、qml/、plugins/、native/；切换版本前先从托盘退出旧进程，避免单实例机制唤起旧版本。

```powershell
# 已在本地 .tools 下准备 Qt 6.8.3 / MinGW / CMake 时，构建、测试并部署
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -Test -Deploy

# 使用自己安装的 Qt 开发套件（含 Widgets、Qt Quick 与 Quick Controls）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1 -QtRoot C:/Qt/6.8.3/mingw_64 -Test -Deploy
```

通用 CMake 构建（Qt >= 6.8，CMake >= 3.24，C++17；推荐已验证的 Qt 6.8.3）。Qt 套件必须包含 Widgets、QuickWidgets、QuickControls2，以及 Network、Concurrent；测试还需要 Test：

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/kit -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
cmake --install build --config Release --prefix /absolute/path/to/dist/Still
```

Windows 请使用与 Qt 开发套件匹配的 MSVC 或 MinGW 编译器；macOS 需要 Xcode Command Line Tools 和 macOS 对应的 Qt 开发套件，安装结果是 `Still.app`，含 Still 显示名称与 ICNS 图标，已在 Apple Silicon Mac 编译通过。本项目不使用 Qt WebEngine。QML 模块与依赖由 `qt_generate_deploy_qml_app_script` 部署；CMake 项目名和应用 target 均为 `Still`，放在 `src/CMakeLists.txt`，避免 QML 导入扫描进入 `.tools/`。

Apple Silicon Mac 可用 `brew install qtbase qtdeclarative` 安装所需 Qt 模块。CLion 可使用内置 CMake 和 Ninja，在 CMake 选项中设置 `-DCMAKE_PREFIX_PATH=/opt/homebrew -DQt6_DIR=/opt/homebrew/lib/cmake/Qt6`，重新加载后选择 `Still` 目标运行。使用 Homebrew 的统一前缀，让 Qt 能找到分属不同 formula 的模块。

若本机 Qt 6.8.3 MinGW 已装 qtbase、缺少 QML 模块，可用项目已有的 aqt 补装（从项目根目录运行，Python 环境需已安装 aqt）：

```powershell
python -m aqt install-qt windows desktop 6.8.3 win64_mingw --outputdir .tools/Qt --archives qtdeclarative
```

## 使用

| 操作 | Windows 默认键 | macOS 对应键 |
| --- | --- | --- |
| 框选后编辑 | Ctrl+1 | Command+1 |
| 框选后直接复制 | Ctrl+2 | Command+2 |
| 每屏截图并贴图 | Ctrl+3 | Command+3 |
| 显示 / 隐藏全部贴图 | Ctrl+4 | Command+4 |
| 滚动长截图 | Ctrl+5 | Command+5 |
| 剪贴板内容贴图 | Ctrl+Shift+V | Command+Shift+V |
| 关闭全部贴图 | Ctrl+Shift+Q | Command+Shift+Q |
| 呼出剪贴板历史 | Ctrl+Alt+Space | Command+Shift+Space |

快捷键可在设置中更改；占用时保留旧键。清空组合键会注销该功能的全局快捷键。Windows 升级后，旧默认的剪贴板快捷键会改为 Ctrl+Alt+Space，其他自定义组合保留。

截图和编辑工具栏使用图标按钮，悬停显示当前界面语言的名称及快捷键；线宽保留数字。窗口较窄时可从“更多工具”展开其余操作。

- **截图**：先冻结所有屏幕，再拖动框选或点击吸附窗口；八个手柄调整选区。Enter 执行默认动作，Esc 取消，C 复制放大镜颜色。一次选区限于单屏。
- **精确宽高**：框选后可在工具条输入宽、高，单位为最终图像像素；自由比例时范围从 1 像素到当前帧整幅，修改一维保留另一维。输入框中的 Enter 提交数值；也可直接点击输出按钮提交。尺寸超出右侧或下侧时只平移选区，保留输入尺寸。鼠标、手柄和方向键调整会同步更新读数。快速复制和长截图可按住 Shift 松手进入精调，调整后回到选区按 Enter 或点击操作按钮完成；Esc 取消。
- **固定比例**：在宽高旁选择 1:1、4:3、16:9、3:4 或 9:16，当前选区及后续框选按输出像素保持该比例。宽高按比例的整数倍对齐，非倍数输入就近调整，受整幅尺寸上限约束；方向键按一个比例单位缩放，Shift 为十个单位，Alt 按输出像素移动，Shift+Alt 为十个像素。鼠标移动和缩放保持比例，切回“自由比例”保留当前选区并解除约束。比例仅属于本次框选窗口，不跨截图保存；小帧仅提供可容纳最小整数单位的比例。
- **延时截图**：菜单栏图标“更多操作 → 延时截图…”可设置 1–60 秒，默认 5 秒。点击“开始倒计时”后可切到目标窗口，倒计时结束再冻结屏幕并框选，沿用当前选区完成动作。点击“取消”、关闭倒计时窗口或在该窗口按 Esc 均可取消，不采集图片；倒计时期间使用普通截图会取消等待并立即开始。重复打开延时入口不会重置当前计时。
- **重复上次区域**：本次运行中确认过选区后，可从菜单栏图标“更多操作 → 重复上次区域”重新采集同一屏幕区域的新画面，沿用当前“选区完成后”的动作。普通截图仍重新框选，取消与整屏截图不覆盖已确认区域。源屏幕移除或区域超出当前屏幕范围时提示重新框选；记录不跨应用重启保存。
- **区域预设**：完成一次框选后，打开“更多操作 → 区域预设…”，为上次确认的区域输入名称并保存。选中预设后点击“截取所选”、在列表按 Enter 或双击，即可截取新画面；名称输入框中的 Enter 用于保存。预设可跨重启复用，同名不会覆盖，删除前需确认。调用成功会更新“重复上次区域”，沿用当前完成动作；原屏幕无法唯一匹配或范围已失效时提示重新框选。预设记录屏幕位置和范围，输出像素尺寸仍受当前屏幕与截图缩放设置影响。
- **编辑**：矩形、圆角矩形、椭圆、直线、箭头、画笔、荧光笔、马赛克、马赛克笔、文字、序号，支持颜色、线宽、撤销重做。`R G O L A P H M B T D` 切工具；Ctrl/Cmd+C 复制、S 打开保存对话框、Shift+S 快速保存、P 贴图、O 复制识别文字。
- **OCR 校对**：截图 OCR 和编辑器“复制文字”保留识别后直接复制，同时打开结果窗口；图片贴图从“更多操作 → 校对识别文字…”打开当前识别结果。校对稿可编辑，原始结果可单独查看和复制；换行、空格默认保留，选择规则后点击“应用整理”才处理当前稿，整理和还原原文均可撤销。复制按钮按当前页复制选区或全文，选中文字可按系统方式拖出；编辑稿拖动默认可移动，按系统复制修饰键拖动可复制。结果为当前识别的独立快照，不改图片、标注或贴图选字坐标；关闭窗口不保存校对稿。
- **API 文字校对**：通用偏好底部“API 文字校对设置…”可填写完整 Chat Completions 地址、模型和自备密钥；不预设服务或模型。本机 OCR 和“应用整理”继续无需密钥。结果窗口可选择“API 校对选中文字…”或“API 校对全部文字…”，确认待发送文字、地址和模型后点击“发送校对”；只提交此次文字快照，不附图片、剪贴板历史或其他上下文。返回结果可编辑，点击“应用到校对稿”才修改，可撤销，原始结果和选区外文字保留。设置提供固定样例连接测试、取消及当前地址密钥删除；密钥进入系统凭据存储，不进入配置备份。取消仅停止本机等待，服务可能已处理并计费。
- **修改当前标注**：按 `V` 进入选择，单击标注轮廓选择最上层对象；空心形状的内部不算轮廓。拖动移动，方向键按源图片像素微调 1 px，Shift+方向键为 10 px。选中后用原颜色、线宽控件改样式，文字与序号可按 F2 或双击改字；取消保留原文，确认空文字删除该标注。画布中的 Delete/Backspace 删除选中对象，选择模式未选中时不操作；绘制模式未选中时保留原有撤销行为。Esc 先取消当前手势或选择，再按一次关闭编辑器；切工具也取消未完成手势。移动、改字、样式和删除均可撤销重做。
- **裁切与图像处理**：在编辑器按 `C`，拖动选择保留区域，按 Enter、再按 C 或点击“应用裁切”提交；Esc 取消。裁切按钮下拉提供水平翻转、垂直翻转、灰度、反色和亮度，均可撤销重做。亮度支持 -100 至 100 的实时预览，负值变暗、正值变亮；点击“应用”提交一次，取消或确认 0 保留原状态与重做记录。颜色处理作用于当时画幅内的图片与已有标注，保留透明度；之后新增的标注仍按所选颜色正常绘制。已有对象继续可编辑，修改时仍经过原有处理。提交修改会取消编辑器内旧的 OCR 请求，需重新识别。
- **贴图**：图片上的文字自动在本机识别。鼠标拖选文字后 Ctrl/Cmd+C 复制选中部分；未选字时复制图片。Ctrl/Cmd+A 选择全部文字。拖动空白移动窗口，Alt 拖动强制移动。滚轮缩放、Ctrl/Cmd+滚轮透明度、空格编辑、右键更多操作。左键双击在当前贴图附近显示小型非模态关闭浮层，不抬高主窗口；默认“取消”，Esc／外点也取消。仅勾选“下次不再提示”并确认关闭后保存偏好；取消不保存。之后双击直接关闭，拖选文字不变。
- **编辑已有贴图**：空格打开编辑器，完成后点“应用并关闭”更新原贴图，文字位置会重新识别。原贴图作为底图，本次新增的标注在当前编辑器内可继续修改。
- **文字与富文本贴图**：剪贴板文字可用上述快捷键或菜单栏“贴图操作”直接贴出；历史中的文字、HTML 与链接复用原贴图入口，按内容显示“文字贴图”或“富文本贴图”。有 `text/html` 时自动显示 Qt 支持的标题、粗斜体、列表、表格和预格式文本等只读排版，支持选择、全选和长文本滚动；仅有 RTF 时仍按纯文本展示。纯文本复制保留原文的换行和空白；富文本复制当前可见文字，选中时复制选区，否则复制全文，不携带 HTML 或改用原始后备文本。拖动标题移动，右下角调整大小，Esc 或关闭按钮关闭。图片优先于文字，文件 URL 不作为路径文字贴出；文字不经过 OCR，原文与 HTML 合计最多 32 MiB UTF-8。两类文字贴图均支持关闭恢复和正常退出会话恢复。
- **贴图恢复**：贴图右键“更多操作”或菜单栏图标“贴图操作”中可恢复最近关闭的贴图。关闭栈仅限当前运行，最多 20 项、256 MiB，至少保留最近一项。正常退出时，未关闭贴图的图片或原文、位置、尺寸、透明度和置顶状态保存为独立会话；可从菜单栏“贴图操作 → 恢复上次贴图会话”手动恢复，或在通用偏好开启“启动时恢复贴图”（默认关闭）。会话不依赖截图历史；屏幕变化时窗口约束到当前可用屏幕。内容缺失或数量上限会提示并保留原会话。
- **右键菜单**：图片贴图主菜单只保留复制当前内容、保存、编辑、更多操作和关闭；文字贴图为复制、全选、更多操作和关闭。旋转、重新识字、恢复和批量操作收进二级菜单。菜单栏图标主菜单保留截图、剪贴板、贴图操作、更多操作、设置与退出；功能和既有快捷键保持。
- **保存**：截图选区、编辑器和长截图工具栏提供“快速保存”；贴图右键也可操作。Ctrl/Cmd+S 保留保存对话框，Ctrl/Cmd+Shift+S 直接保存到默认目录（未设置时为系统图片文件夹）。通用偏好可设置文件名模板及预览：`{date}` 为 yyyyMMdd、`{time}` 为 HHmmss、`{ms}` 为毫秒；同名自动加 `-2`、`-3`，快速保存不覆盖已有文件。支持 PNG 无损压缩 0–100 和 JPEG 质量 1–100。设置会应用到已打开的编辑器和贴图，保存后复制图片遵循同一设置。快速保存失败时编辑内容保留；选区/长截图结果会转入编辑器供重试。
- **复制为文件**：通用偏好中的“复制为图像文件”默认关闭。开启后，截图、编辑器、贴图的图片复制及保存后复制会使用当前文件名模板、PNG/JPEG 格式和参数，向剪贴板放入临时文件引用；关闭时仍复制原图片。OCR 选字仍复制文字，剪贴板历史重放保持原格式。临时文件保留在系统临时目录中的独立文件夹，窗口关闭、剪贴板变化和应用退出均不主动删除；系统清理后，相应文件历史引用可能失效，需长期保留时请正常保存。
- **滚动截图**：先框选原页面的可滚动内容，再点击选区工具条的“长截图”；也可按Ctrl+5后框选。采集中选区边框持续可见且鼠标穿透，将鼠标移入原页面选区，缓慢向下滚动。右侧以固定比例预览，图宽最多160逻辑像素，随内容增长不再缩小；超过360px视口后用滚轮或PageDown回看完整长图，额外8px滚动条。位于底部时跟随新增内容，滚回查看时保留位置；蓝框标记全图、绿框标记最后成功采集的可见部分。下方工具条保留42px操作行高度、32px按钮、20px图标、7×5px边距与2px间距，保留14px柔和外圆角；总宽随尺寸和只读“纵向”标签变化。工具条提供编辑、文字识别、贴图、保存、取消、复制图标，复制入口以浅银灰强调。编辑进入普通截图编辑器，其余输出复用普通截图动作；取消不输出，达到限额或自动结束仍将最后成功结果交给编辑器。仅支持手动纵向滚动，没有横向或自动滚页按钮。预览初次出现不抢页面焦点，显式交互可获取焦点，优先放在选区右侧并约束在屏幕可用边界内。静止画面等待用户，不消耗有效拼接帧数；短暂无法对齐时保留已有结果并继续等待，可暂停或稍向上滚动找回重叠，不强行拼接不可靠画面。
  Windows 10 2004及以上且DWM桌面合成可用时，使用系统 `WDA_EXCLUDEFROMCAPTURE` 排除伴随层，允许预览覆盖选区而不进入长图；这不是通用的内容安全保证，兼容条件见[微软API说明](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)。不支持排除时，边框绘制在采集像素之外，预览只放在选区外；没有安全空间则提示缩小选区。采集过程中不通过隐藏或闪烁预览避开截图。
- **剪贴板**：主窗口默认内容页，单列记录文字、HTML/RTF富文本、图片、文件路径及有限其他格式。左侧缩略图／类型图标，中间标题与最多两行摘要，右侧时间与固定。顶部页名、计数和搜索同行，类型筛选栏右侧保留更多，有粘贴目标时显示粘贴按钮。已固定从侧栏进入，暂停记录在侧栏底部。搜索框聚焦时收起列表选中高亮，保留当前条目；按上下键进入列表逐项选择，列表上下、左右均逐项。Enter 按偏好粘贴或复制，Ctrl+Enter 仅复制并保留窗口，Ctrl+Shift+Enter 纯文本，Esc 收起。失焦不自动收起。更多菜单或空格可展开预览，紧凑窗口隐藏预览。悬停记录可复制、固定或删除，列表仍支持 Ctrl+C 复制、右键菜单与 Delete 删除后选相邻条目。文件显示名称与缩短父目录，预览保留完整路径。连续工作面不包列表／预览外框，仅以细竖线分隔；更多与右键菜单统一主题，Esc 优先关闭菜单。
  从外部用快捷键打开时记录粘贴目标；鼠标切到其他应用再回到主窗口时，旧目标失效，按钮改为“复制内容”，保留窗口并提示手动粘贴，避免粘到旧应用。

## OCR 与系统权限

Windows 使用系统 `Windows.Media.Ocr`，在后台通过 PowerShell 返回文本与词级位置框，需要系统安装对应 OCR 语言包。macOS 使用 Apple Vision，通过 Objective-C++ 与 Qt 接入；截图需要系统屏幕录制授权。图像和文字不会上传。

文字选择的最小单位取决于 OCR 返回的位置框，**不保证所有语言都能逐字选择**。旋转或编辑后的贴图会清除旧文字并重新识别，避免坐标错位；马赛克后的图片按实际可见内容重新识别。

复制所选文字保留识别文本在所选范围内已有的空格、制表符、标点和换行；全选与复制全部文字还保留首尾空白。拖选到文字框外时，按离文字框最近边缘的距离延伸选择。

OCR 最多同时运行两个任务；同一窗口再次识别会替换旧请求，关闭窗口会释放尚未开始的识别图片。已进入系统识别的任务在返回后释放图片。内存修复与验证证据见 `docs/MEMORY-FIXES.md`。

## 数据与迁移

项目、构建目标、C++ 命名空间、QML URI、组织名和实例标识统一使用 Still。Windows 新安装使用 `%LOCALAPPDATA%/Still`，macOS 使用 Qt 的 Still 应用数据目录。若新目录没有数据，自动沿用旧版 PixClone 数据目录，保留设置与历史，不搬动原文件。可用 `STILL_DATA_DIR` 指定独立数据目录；未设置时兼容旧版 `PIXCLONE_DATA_DIR`。新目录标记使用 `.still-history` / `.still-clipboard`，兼容读取旧版标记。macOS bundle ID 为 `local.still.app`，更改标识后可能需要重新授予屏幕录制和辅助功能权限。

- `qt-settings.json`：Qt 设置，原子写入；没有 Qt 设置时读取旧 `settings.json` 中可复用的字段。旧设置文件不被改写。
- `appearance.language` 为 `zh_CN` / `en`，`appearance.theme` 为 `system` / `light` / `dark`；缺省分别为 `zh_CN` / `system`。英文词条见 `assets/en.json`，由 `QTranslator` 加载，QML 使用 `qsTranslate` 与引擎重翻译，不迁移用户内容。
- `History/*.png`：默认历史目录，兼容读取旧 PNG；设置 `history.dir` 后使用指定目录，配置文件仍保留在应用数据目录。Qt 版本按文件扫描，不依赖旧 `history.json` 索引。
- `PinSessions/session.json` 和 `PinSessions/session-*/*.{png,txt,html}`：正常退出时提交的贴图会话，独立于历史配额。v3 为富文本同时保存 UTF-8 原文后备与 HTML；所有内容完整写入新目录后才原子提交索引，兼容读取 v1/v2 会话。成功后才清理上一次会话内容，失败保留旧文件；富文本的任一内容文件缺失或损坏时跳过整张贴图，恢复不完整时保留旧会话。未恢复且本次没有贴图活动时，不覆盖原会话。旧版程序不支持 v3，会拒绝读取并保留原索引，不会静默丢弃富文本格式。
- `Clipboard/index.json` 与 `Clipboard/*.clip`：默认剪贴板目录；设置 `clipboard.dir` 后使用独立目录。内容只保存在本机，未加密，可暂停记录或清空；识别到应用提供的“不记录”标记时跳过，不保证所有密码来源都会提供此标记。
- 剪贴板缩略图最多128×96px，PNG不超过17000 bytes，base64小于24000字符；保持索引最多2000条、读取上限64 MiB，原始图片与格式数据不改写。
- 原交接文档保存在 `docs/HANDOVER-ELECTRON.md`；当前说明见 `docs/HANDOVER.md`。
