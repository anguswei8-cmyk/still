# 剪贴板管理

日期：2026-10-30。Qt Widgets 实现，复用既有图标、图片编辑器、贴图和保存流程，无新增第三方依赖。

## 操作

主窗口启动默认显示剪贴板内容。Windows 默认 Ctrl+Alt+Space（可在快捷键页修改）及托盘入口都打开同一主窗口的内容页，不再弹出独立面板。输入搜索，↑↓ 选择；Enter、双击或主按钮默认收起主窗口并回到之前的窗口粘贴。Ctrl+Enter 仅复制且保持主窗口，Ctrl+Shift+Enter 纯文本粘贴，Esc 收起。顶部“设置”显示偏好，内容页齿轮直接定位剪贴板设置；失焦不自动隐藏。设置可将默认动作改成仅复制。

可按文字、图片、文件、链接/其他、已固定筛选，支持固定、删除、暂停和清空。图片可直接编辑、贴图、保存。清空默认保留固定条目，可在确认框选择一起删除。删除文件条目不会删除原文件。

## 格式与本地存储

- 保存文字、HTML/RTF、PNG 图片、文件/链接 URL 与有限自定义 MIME。富文本仅以纯文本预览，避免预览执行内容或加载外部资源。搜索匹配标题、前 4096 字符预览和格式名，不是全文索引。
- 文件只记录引用，恢复时按复制处理，避免重放旧剪切导致移动原文件；原文件移动/删除后提示不可用，仍可纯文本粘贴路径。网络路径不在后台主动做存在性探测。邮件虚拟附件须先另存为本地文件。
- 默认目录为应用数据目录下的 `Clipboard`；在“设置→剪贴板”选择专用空目录（例如 `D:/PixCloneClipboard`），确认目录后自动迁移已有条目，无需保存按钮。与截图历史及手动保存目录相互独立。
- 默认 200 条 / 256 MiB，可调至 2000 条 / 10240 MiB；容量按编码后的内容文件计，不含索引与文件系统开销。优先清理最早的非固定条目。固定条目不自动删；新条目必然放不下时拒绝新增，保留原历史。
- `.clip` 使用版本化 JSON/base64 与 SHA-256 内容名，`index.json` 只存元数据和缩略图；用 QSaveFile 原子提交。专用目录标记和锁防止误用普通文件夹或被第二个实例同时写。损坏索引会停止写入并提示，不能悄悄覆盖为新历史。
- 迁移先复制并校验，原子写入可读取的目标索引，再保存新目录设置。设置保存失败会恢复目标旧索引并保留源数据。设置保存成功后才应用配额和清理旧副本。若进程在切换中退出，旧配置仍可读取源历史，已保存的新配置可读取目标索引。
- 预览与复制、粘贴等显式操作有独立的读取生命周期。替换或关闭预览只取消预览，归档在工作线程读取前和结果投递前核对请求代次。

历史只保存在本机，未加密。可在设置关闭记录，或在面板临时暂停。遵守可识别的 Windows 不记录标记、KDE 密码提示及 macOS Concealed/Transient 标记；无法保证所有应用都会标记敏感内容。

## 资源与系统边界

原始图片最大 128 MiB，且不超过 32 Mi 像素；捕获、编码与读取共用像素上限，避免记录后无法恢复；序列化格式内容合计最大 32 MiB，最多 64 个格式。后台待写队列最多 8 条 / 128 MiB。后台完成 PNG 编码和持久化后释放原始像素，列表仅留最大 64×48 缩略图；完整内容按需加载，隐藏面板取消过期读取，不常驻整批大图。

Windows 粘贴前验证原窗口仍存在且处于前台，并检查按键状态与本次剪贴板标记；发生新操作/目标切换时不向其他窗口注入文字。不能恢复前台、权限不匹配或系统限制时提示手动粘贴。macOS 已接入目标应用恢复与 Command+V，自动粘贴需要辅助功能授权，尚未在 Mac 编译验收。私有格式依赖提供方实现，不能承诺任意软件都能跨进程或重启重放。

主窗口失焦且没有活动菜单/模态对话框时，丢弃此前的粘贴目标并取消待处理动作。鼠标返回不会猜测目标，主按钮退回“复制内容”，完成后保留窗口；从外部再次使用快捷键/托盘打开会重新记录目标。正常粘贴先捕获目标再收起窗口，避免窗口隐藏时的失焦事件抹掉本次目标。

Qt 剪贴板/MIME 行为参考 [QClipboard](https://doc.qt.io/qt-6/qclipboard.html)、[QMimeData](https://doc.qt.io/qt-6/qmimedata.html)；系统输入限制参考 [Microsoft SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)。

## 已验证

九组 CTest 全部通过。剪贴板专用测试覆盖富文本/私有格式往返、图片像素、文件复制语义、排除标记、损坏内容、重启恢复、去重/固定、配额拒绝不丢旧历史、迁移失败、锁冲突与大图归档后释放。设置测试覆盖配置失败时两类历史和旧热键均保留；界面测试覆盖筛选、删除、复制格式、暂停与恢复。

旧独立面板的原生完整流程在 Windows 单独运行成功，证据为 `build/clipboard-native-interactive-results.txt`。当前单窗口版本的真实系统联动需在前台权限环境重新验收，不能沿用旧证据视为已通过。当前主窗口截图为 `.impeccable/review/main-clipboard.png` 与 `main-clipboard-settings.png`，使用合成数据；`clipboard-*.png` 只是组件测试抓图，不代表产品还存在独立窗口。

未验证 Mac、跨权限目标应用、所有第三方私有格式、断电恢复及数小时内存压力。不宣称系统中所有剪贴板格式都能完整重放。
